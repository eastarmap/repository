EastarMap.Chart .NET SDK 二次开发手册

本手册面向二次开发，系统梳理 code/cycle/net_api 中 EastarMap.Chart（L2 门面层）已封装接口的分类、各函数详细说明与可运行示例代码， 帮助快速定位对应 API。

SDK 分层溯源链 ogc_chart_c_api（C ABI，ogc_* 导出，931 个） → L1 EastarMap.Chart.Interop（P/Invoke 绑定，929 个，域 108——仅 JNI 2 项不属 .NET 范围未绑定） → L2 EastarMap.Chart（本手册对象，托管门面，929 个引用——v1.4 索引口径，2026-11-13 M6） → 测试/示例（测试覆盖 73 项）。二次开发只应使用 L2 门面，禁止直接 P/Invoke（架构守卫强制）。

快速开始

1. 引用程序集与目标框架

  • NuGet 包 EastarMap.Chart（版本 2.0.2-preview.21109，依赖 EastarMap.Chart.Interop 2.0.1.21101），随包内置 runtimes/win-x64/native/ 原生库。
  • 目标框架：net8.0（主，P/Invoke 走 [LibraryImport] 源生成）；net472（兜底，同清单 [DllImport]）。
  • 命名空间按域划分：EastarMap.Chart.Compatibility / Data / Display / ErrorHandling / Extensibility / Geo / Geometry / Layers / Query / Rendering / S57 / S101 / Security / Symbology / Transform / Viewer / Drawing / Imaging / Coverage / Navigation / Alerts / Ais。

2. native 库定位（重要前置）

NativeResolver 按回退序解析 ogc_chart_c_api： EASTARMAP_NATIVE_BIN 环境变量 → 应用目录 → install\bin → PATH。 未解析时 L2 门面统一抛 ChartSdkException（消息含探针明细）。

3. 最小可运行骨架

using EastarMap.Chart.Compatibility;
using EastarMap.Chart.S57;
using EastarMap.Chart.Rendering;

static void Main()
{
    var version = SdkVersion.Version;          // "2.0.2.21109"
    var root    = EastarMapEnvironment.AppRoot;  // native 树根
    var engine  = PortrayalEngine.Create(new PortrayalEngineOptions { S52RootPath = root });
    using var parser = S57Parser.Create();
    parser.Open(@"E:\CN422111.000");
    var handle = parser.Parse();
    engine.Dispose();
    Console.WriteLine($"版本 {version}，解析句柄 {handle}");
}

4. 架构约束速记

  • 所有句柄类（PortrayalEngine / S57Parser / ImageDevice / ...）实现 IDisposable，用 using 或显式释放。
  • 返回 NULL / 非 0 错误码 → 门面抛 ChartSdkException（携带 native 错误码与消息）。
  • 双 TFM 同构：同一份代码在 net8.0 与 net472 行为一致。
