EastarMap.Chart .NET SDK 二次开发手册

本手册面向二次开发，系统梳理 code/cycle/net_api 中 EastarMap.Chart（L2 门面层）已封装接口的分类、各函数详细说明与可运行示例代码， 帮助快速定位对应 API。

SDK 分层溯源链 ogc_chart_c_api（C ABI，ogc_* 导出，925 个） → L1 EastarMap.Chart.Interop（P/Invoke 绑定，230 个） → L2 EastarMap.Chart（本手册对象，托管门面，158 个引用） → 测试/示例。二次开发只应使用 L2 门面，禁止直接 P/Invoke（架构守卫强制）。

本手册覆盖范围：已封装接口 vs 未封装接口

已封装（本手册覆盖，二次开发可用） 仅 EastarMap.Chart（L2 门面层，158 个 native 引用）对应的托管类/方法，按 Compatibility / Data / Display / ErrorHandling / Extensibility / Rendering / S57 / Security / Symbology 九个命名空间划分，即本手册各模块所记录的全部内容。
未封装（本手册不覆盖，二次开发不可直接调用） native ogc_chart_c_api 共 925 个 ogc_* 导出，其中 695 个尚未绑定（L1 未包装）——这些接口未封装，例如：
  • 按域未封装：ais / alert / alert_zone / cache_manager / chart_viewer / geometry / feature / envelope(部分) / coordinate / coord_transformer / datasource / draw_context / draw_device / filter / geo / image / hit_test / field_defn / field_value / chart_parser / chart_plugin / coverage / cpa / circuit_breaker / collision / driver_manager / error_recovery / graceful_degradation / health_check / plugin / …
  • 这些域在 L2 无门面类，二次开发不得绕过封装直接 P/Invoke（架构守卫强制，且可能缺安全释放）。
边界判定方法 判断某个能力是否已封装：在 src\EastarMap.Chart\** 中是否存在对应 public 门面类/方法。存在 = 已封装（见本手册）；不存在 = 未封装（待阶段二/三，勿直接使用）。常见"仅部分封装"的域已在对应模块内标注。

快速开始

1. 引用程序集与目标框架

  • NuGet 包 EastarMap.Chart（版本 2.0.1-preview.21101），随包内置 runtimes/win-x64/native/ 原生库。
  • 目标框架：net8.0（主，P/Invoke 走 [LibraryImport] 源生成）；net472（兜底，同清单 [DllImport]）。
  • 命名空间按域划分：EastarMap.Chart.Compatibility / Data / Display / ErrorHandling / Extensibility / Rendering / S57 / Security / Symbology。

2. native 库定位（重要前置）

NativeResolver 按回退序解析 ogc_chart_c_api： EASTARMAP_NATIVE_BIN 环境变量 → 应用目录 → install\bin → PATH。 未解析时 L2 门面统一抛 InvalidOperationException（消息含探针明细）。

3. 最小可运行骨架

using EastarMap.Chart.Compatibility;
using EastarMap.Chart.S57;
using EastarMap.Chart.Rendering;

static void Main()
{
    var version = SdkVersion.Version;          // "2.0.1.21101"
    var root    = EastarMapEnvironment.AppRoot;  // native 树根
    var engine  = PortrayalEngine.Create(new PortrayalEngineOptions { S52RootPath = root });
    using var parser = S57Parser.Create();
    parser.Open(@"E:\CN422111.000");
    var handle = parser.Parse();
    engine.Dispose();
    Console.WriteLine($"版本 {version}，解析句柄 {handle}");
}

4. 架构约束速记

  • 所有句柄类（PortrayalEngine / S57Parser / ImageDevice / ...）实现 IDisposable，用 using 或显式释放。
  • 返回 NULL / 非 0 错误码 → 门面抛 ChartSdkException（携带 native 错误码与消息）。
  • 双 TFM 同构：同一份代码在 net8.0 与 net472 行为一致。

运行与部署要点

  • native 测试环境：install\bin（118 文件，SHA 冻结于 native\native-manifest.json）。
  • S-57 样例图幅：E:\CN422111.000。
  • 授权：引擎创建可传 LicenseFilePath（config\license.lic）或 CredentialName（凭据库），详见 ⑥。

    dotnet build EastarMap.Chart.sln -c Release
