① 环境与版本（命名空间 EastarMap.Chart.Compatibility）

本模块是 SDK 的环境锚点：统一收敛 native 各目录路径推导（架构规则 ARCH-01/02），并提供版本真源握手。是绝大多数二次开发的第一步。

类类别职责源文件
EastarMapEnvironmentstatic11 个只读目录 + 目录创建 + 线程局部错误码Compatibility\EastarMapEnvironment.cs
SdkVersionstatic版本字符串 / 构建日期 / int 三元组Compatibility\SdkVersion.cs
native 未加载时的行为 所有 getter / 方法都会先经 NativeResolver.EnsureLoaded()；解析失败抛 InvalidOperationException，消息含回退序探针明细（EASTARMAP_NATIVE_BIN → 应用目录 → install\bin → PATH）。

EastarMapEnvironment（环境目录锚点门面）

转发 C 侧 EastarMapEnv 单例（路径推导唯一收敛点）。所有 getter / 方法均先经 NativeResolver.EnsureLoaded() 加载守卫，native 未加载时抛 InvalidOperationException；目录 getter 在 native 已加载而对应路径未推导出时返回 null。

静态只读目录属性

public static string? AppRoot { get; }
应用根目录（native 侧锚点 = 进程 exe 目录）。
public static string? ConfigDir { get; }
配置目录。
public static string? ResourcesDir { get; }
资源目录。
public static string? ReportsDir { get; }
报告目录。
public static string? S101ResourceDir { get; }
S-101 资源目录（S-101 部署锚点）。
public static string? S52ResourceDir { get; }
S-52 表达资源目录（含 portrayal.sdb，渲染引擎根路径默认值来源）。
public static string? ProgramDataDir { get; }
ProgramData 可写目录。
public static string? ProgramDataStateDir { get; }
ProgramData 状态子目录。
public static string? LocalAppDataDir { get; }
LocalAppData 可写目录。
public static string? LocalAppDataStateDir { get; }
LocalAppData 状态子目录。
public static string? TempDir { get; }
临时目录（TEMP/TMP → TMPDIR → /tmp；不带尾分隔符，盘符根除外）。

方法

public static int EnsureDirectory(string dir)
递归创建目录；0 = 成功（幂等），否则返回 OGC 错误码。
参数：
dir要创建的目录路径。
返回：0=成功，非 0 为 OgcErrorCode。

属性

public static int LastError { get; }
最近一次 ogc_env_* 调用的线程局部错误码（0 = 成功）。

示例

using EastarMap.Chart.Compatibility;

Console.WriteLine($"AppRoot = {EastarMapEnvironment.AppRoot}");
Console.WriteLine($"S52 资源 = {EastarMapEnvironment.S52ResourceDir}");
Console.WriteLine($"临时目录 = {EastarMapEnvironment.TempDir}");

// 创建嵌套目录（幂等）
var rc = EastarMapEnvironment.EnsureDirectory(Path.Combine(workDir, "nested", "logs"));
if (rc != 0) Console.Error.WriteLine($"创建失败，错误码 {rc}");

// 读取线程局部错误码
var err = EastarMapEnvironment.LastError;

SdkVersion（SDK 版本真源握手）

版本字符串 / 构建日期 / int 三元组均以 native 函数返回值为真源（头文件 #define 仅镜像）。版本 / 构建日期返回值必须配对释放（[Alloc] 语义，门面内部完成）。

属性

public static string Version { get; }
版本字符串 "major.minor.patch"（实测 2.0.2.21109（构建日期 Nov 9 2026））。
public static string BuildDate { get; }
构建日期字符串。
public static int Major { get; }
主版本号。
public static int Minor { get; }
次版本号。
public static int Patch { get; }
修订号。
public static bool VersionMatchesParts { get; }
版本握手自检：Version 以 Major.Minor.Patch 为前缀。用于验证 DLL 真源与整型三元一致。

示例

using EastarMap.Chart.Compatibility;

var v = SdkVersion.Version;
Console.WriteLine($"native 版本 {v}（构建 {SdkVersion.BuildDate}）");
Console.WriteLine($"int 三元 {SdkVersion.Major}.{SdkVersion.Minor}.{SdkVersion.Patch} 握手：{SdkVersion.VersionMatchesParts}");
if (!SdkVersion.VersionMatchesParts) throw new InvalidOperationException("版本握手不一致");
典型用途 启动自检、日志打印版本、做版本兼容分支。详见示例 samples\EastarMap.Chart.ConsoleSmoke\Program.cs（StepL0）。
