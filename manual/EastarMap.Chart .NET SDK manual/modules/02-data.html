② 数据入库与查询（命名空间 EastarMap.Chart.Data）

本模块把 S-57 海图入库到 SQLite（dump）、对库内数据集进行元信息/要素查询（query），并提供用户航线库（EDB）增删改查。是构建数据后台的核心模块。

类类别职责
入库（dump）
DumpOptionsPOCO16 键契约选项（mode/sqlitePath/inputs/…）
ChartDumpstatic同步/异步执行入库，带进度回调
DumpReportDTO执行结果（totals + 逐文件明细）
DumpProgressEventArgs事件参数逐文件进度（current/total/fileName）
DumpServicestatic低阶 JSON 进出入口（ogc_dump_execute 裸包装）
查询（query）
FeatureQuerystaticcells/inspect/features 查询 + 过滤 + EDB 归一
FeatureQueryFilterPOCO要素查询过滤（bbox/objectClasses/offset/limit…）
FeatureSummaryDTO要素统一摘要
FeatureGeometryDTO要素几何摘要（WKB/WKT）
FeatureAttributeDTO属性键值对（Name/Value/RawJson）
CellSummaryDTO数据集元信息（范围/版次/机构）
用户航线库（EDB）
UserRouteDatabaseIDisposable打开/建 schema/要素增删改查（可加密）
EdbFeatureDTOEDB 要素（fid/attributes_json/geom_wkt）
契约键名 DumpOptions 序列化后与 C 侧 DumpConfig/DumpConnectionConfig 键名一一对应；凡「查询」也复用同一套 16 键（mode=features/inspect/cells），保证键名一致。

DumpOptions（入库/查询契约 16 键强类型）

所有 dump/query 调用的入参载体。序列化保持契约键名。

属性

属性类型说明
Modestring模式：dump | remove | inspect | cells | features。
SqlitePathstringSQLite 目标路径（UTF-8）。
InputsIReadOnlyList<string>输入海图文件（mode=dump）。
CellIdstring数据集 id（mode=remove|inspect|features）。
Overwritebool目标已存在时覆盖。
CreateSpatialIndexbool建空间索引（默认 true）。
BatchSizeint每批要素数（默认 100）。
SerialModebool串行模式（默认 true）。
UseTransactionbool事务包裹（默认 true）。
Sridint空间参考 id（默认 4326）。
Bboxdouble[]?要素过滤框 [minx,miny,maxx,maxy]（lon,lat 序）。
ObjectClassesIReadOnlyList<string>对象类过滤（如 DEPARE）。
Offsetint分页偏移。
Limitint分页上限。
LastFidstring增量起点 fid。
GeometryOnlybool只导几何。

方法

public string ToJson()
16 契约键序列化（键名与 C 契约一一对应）。

抛异常：JSON 为空或非法时抛 ArgumentException / JsonException。

ChartDump（dump 执行门面）

同步/异步执行入库，进度经 unmanaged thunk 进入托管回调。ExecuteAsync 取消经 progress 返 0 生效。

public static DumpReport Execute(DumpOptions options, Func<object?, DumpProgressEventArgs, int>? progress = null, object? state = null)
同步执行。progress 回调返回非 0 继续 / 0 中断；state 透传给回调。
返回：DumpReport。
public static Task<DumpReport> ExecuteAsync(DumpOptions options, EventHandler<DumpProgressEventArgs>? progress = null, CancellationToken ct = default)
异步执行（Task.Run 包裹）。取消时 progress 返回 0 → native 中断。

示例：入库 + 进度 + 异步取消

using EastarMap.Chart.Data;

var sqlite = Path.Combine(workDir, "my-chart.sqlite");

// 同步执行 + 进度回调（返 0 可中断）
var report = ChartDump.Execute(
    new DumpOptions {
        Mode = "dump", SqlitePath = sqlite,
        Inputs = new[] { @"E:\CN422111.000" },
        Overwrite = true, CreateSpatialIndex = true, BatchSize = 100,
    },
    (_, e) => {
        Console.WriteLine($"进度 {e.Current}/{e.Total} {e.FileName}");
        return 1;   // 1=继续；0=中断
    });

if (!report.Success) throw new InvalidOperationException("dump 失败：" + report.Error);
Console.WriteLine($"要素 {report.FeaturesInserted} 行 / 文件 {report.Succeeded}/{report.Files}");

// 异步 + 取消
using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(30));
var rep2 = await ChartDump.ExecuteAsync(opts, (_, e) => Console.WriteLine($"…{e.Current}/{e.Total}"), cts.Token);

DumpService（低阶 JSON 进出入口）

FeatureQuery（查询门面）

强类型查询 SQLite 库，并对 EDB 要素做归一。ogc_query_preview + ogc_dump_json_free 配对释放。

public static IReadOnlyList<string> ListCells(string sqlitePath)
列出目标库内全部数据集 id（mode=cells）。
public static CellSummary InspectCell(string sqlitePath, string cellId)
读取数据集元信息（mode=inspect）。
public static IReadOnlyList<FeatureSummary> QueryFeatures(string sqlitePath, string cellId, FeatureQueryFilter? filter = null)
查询要素（mode=features）。
public static int CountFeatures(string sqlitePath, string cellId, FeatureQueryFilter? filter = null)
单页要素数（mode=features 的 count 段；不随 offset 变化）。
public static FeatureSummary Normalize(EdbFeature feature)
EDB 要素 → FeatureSummary 归一（query 与 EDB 两条链路共用）。
public static IReadOnlyList<FeatureSummary> FilterByObjectClass(IEnumerable<FeatureSummary> features, IEnumerable<string> objectClasses)
按对象类集合过滤（大小写不敏感；空集合 = 全通过）。
public static IReadOnlyList<FeatureSummary> FilterByBbox(IEnumerable<FeatureSummary> features, double[] bbox)
按 bbox 过滤（[minx,miny,maxx,maxy] lon/lat 序；无几何要素不命中）。bbox.Length != 4 抛 ArgumentException。

示例：查询数据集 + 分页 + 过滤

using EastarMap.Chart.Data;

var cells = FeatureQuery.ListCells(sqlite);
var cell  = cells.First();
var meta  = FeatureQuery.InspectCell(sqlite, cell);
Console.WriteLine($"数据集 {meta.CellId} lon[{meta.MinLon},{meta.MaxLon}] lat[{meta.MinLat},{meta.MaxLat}]");

var page = FeatureQuery.QueryFeatures(sqlite, cell,
    new FeatureQueryFilter { Offset = 0, Limit = 256, ObjectClasses = new[] { "DEPARE" } });

foreach (var f in page)
    Console.WriteLine($"{f.ObjectClass} rcid={f.Rcid} geom={f.Geometry.GeometryType}");

UserRouteDatabase（用户航线库门面）

ogc_edb_* 10 函数强类型。明文库 cipherKey=null/空；加密库自定口令（已加密库以空密钥打开会失败）。IDisposable

public static UserRouteDatabase Open(string path, string? cipherKey = null)
打开（必要时创建）用户库。path 为库文件路径，cipherKey 为加密口令（可为空 = 明文库）。
public bool IsOpen { get; }
连接是否有效。
public void EnsureSchema()
幂等建 schema（gis_datasets user 行 + gis_layers 两行 + 两张要素表）。
public void FeatureUpsert(string layerName, string fid, string? geometryWkt, string? attributesJson)
幂等写入/更新一条要素。layer: user_waypoint | user_route。
public void FeatureDelete(string layerName, string fid)
删除一条要素（user_route 级联删其下航点）。
public IReadOnlyList<EdbFeature> FeatureList(string layerName)
列出图层全部要素（fid 升序）。
public EdbFeature? FeatureGet(string layerName, string fid)
按 fid 取单条（null = 未找到）。

示例：EDB 增删改查 + 加密库

using EastarMap.Chart.Data;

var edbPath = Path.Combine(workDir, "user-routes.edb");

// 明文库（cipherKey = null）
using (var db = UserRouteDatabase.Open(edbPath))
{
    db.EnsureSchema();
    db.FeatureUpsert("user_waypoint", "wp-001",
        "POINT(122.51 31.22)", "{\"objectClass\":\"DEPARE\",\"名称\":\"航路点A\"}");
    db.FeatureUpsert("user_route", "rt-001",
        "LINESTRING(122.5 31.2, 122.6 31.3)", "{\"objectClass\":\"FAIRWY\",\"名称\":\"航线1\"}");
}

// 重新打开回读 + 归一
using (var db = UserRouteDatabase.Open(edbPath))
{
    foreach (var f in db.FeatureList("user_waypoint"))
    {
        var sum = FeatureQuery.Normalize(f);
        Console.WriteLine($"{sum.ObjectClass} 名称={sum.GetAttribute("名称")}");
    }
    db.FeatureDelete("user_waypoint", "wp-001");
}

// 加密库（自定口令；已加密库必须以相同口令打开）
using (var enc = UserRouteDatabase.Open(encPath, "my-secret")) { /* … */ }

EdbFeature（用户航线库要素）

属性类型说明
Fidstring要素 id。
AttributesJsonstring属性 JSON。
GeometryWktstring?几何 WKT（无几何为空）。
典型流程 ① ChartDump.Execute 把 S-57 转 SQLite → ② FeatureQuery.ListCells/InspectCell/QueryFeatures/CountFeatures 查询 → ③ 需要用户自定义数据时用 UserRouteDatabase（航线/航点）落库。全程无需手写 P/Invoke。
