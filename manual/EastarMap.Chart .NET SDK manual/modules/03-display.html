③ 显示配置（命名空间 EastarMap.Chart.Display）

本模块提供海图显示设置的载体（DisplayMode / Dpi / ShowGrid）读写。ChartConfig 封装 ogc_chart_config_* 8 个函数。

类类别职责源文件
ChartConfigIDisposable显示配置创建与读写Display\ChartConfig.cs
关于「载体一致」 native 侧目前无渲染消费方（sdk_c_api_graph.cpp:1229-1237 实测），本门面只保证数据载体在 native 往返一致；真正的显示类别/等深线等渲染参数在 ⑥ 渲染模块的 PortrayalRenderOptions 中设置。

ChartConfig（显示配置门面）

句柄生命周期由 SafeChartConfigHandle 托管（释放 = ogc_chart_config_destroy 配对）。IDisposable

静态方法

public static ChartConfig Create()
创建显示配置（默认值由 native 决定）。返回 NULL 时抛 ChartSdkException。

属性（可读写往返）

public int DisplayMode { get; set; }
显示模式（基 IMO/Simplified/Other 载体值）。
public double Dpi { get; set; }
DPI。
public bool ShowGrid { get; set; }
网格显示开关（读 = get_show_grid() != 0；写 = 1/0）。

示例

using EastarMap.Chart.Display;

using var cfg = ChartConfig.Create();
cfg.DisplayMode = 0;           // 0=IMO, 1=Simplified, 2=Other（按需传值）
cfg.Dpi         = 96.0;
cfg.ShowGrid    = true;

Console.WriteLine($"DisplayMode={cfg.DisplayMode} Dpi={cfg.Dpi} ShowGrid={cfg.ShowGrid}");
注意 上面的 DisplayMode = 0 为示例；实际传 int 值（0/1/2）。所有 setter 直接转发 native，不做枚举校验。
