④ 异常处理（命名空间 EastarMap.Chart.ErrorHandling）

本模块统一管理 native 错误码到托管异常的映射，是所有 L2 门面的错误出口。二次开发用 try/catch 捕获 ChartSdkException 即可拿到错误码与消息。

类类别职责源文件
ChartSdkExceptionExceptionSDK 异常（code/module/message）ErrorHandling\ChartSdkException.cs
NativeErrorstatic错误码→异常映射ErrorHandling\NativeError.cs
OgcErrorCodeenum基础错误码实名（0 / -1..-11）ErrorHandling\OgcErrorCode.cs

ChartSdkException（SDK 异常）

承载 native 错误码实名 + ogc_error_get_message 文本。Message 格式："[code] message"。

构造与成员

public ChartSdkException(int code, string message, int module = 0)
构造异常。module 为错误模块实名（portrayal 域用 OgcPortrayalErrorModule；基础域为 0）。
public int Code { get; }
native 错误码（原始 int，与 ogc_error_code_e/ogc_portrayal_error_e 数值一致）。
public int Module { get; }
错误模块实名。

示例：捕获并解读错误

using EastarMap.Chart.ErrorHandling;

try
{
    // 任意 L2 调用（此处以 S57Parser 打开不存在文件为例）
    using var parser = S57Parser.Create();
    parser.Open(@"C:\no-such.000");
}
catch (ChartSdkException ex)
{
    Console.WriteLine($"错误码 {ex.Code}（OGC_ERROR = {(OgcErrorCode)ex.Code}）：{ex.Message}");
    // 按错误码做分支处理
    if ((OgcErrorCode)ex.Code == OgcErrorCode.OGC_ERROR_NOT_FOUND) { /* 文件未找到 */ }
}

NativeError（错误码→异常映射）

public static string Describe(int code)
经 ogc_error_get_message 取 native 消息文本（静态存储，不 free）；未登记错误码返回 "未登记错误码 {code}"。
public static void EnsureSuccess(int code)
断言成功（0），否则抛 ChartSdkException(code, Describe(code))。用于基础域错误。
public static void EnsurePortrayalSuccess(int code, int module)
portrayal 域断言（负码 + 模块实名），抛 ChartSdkException(code, Describe(code), module)。

示例：包装 native 返回码

using EastarMap.Chart.ErrorHandling;

// 典型门面内部用法：非 0 抛异常
int rc = NativeFunctionCall();
NativeError.EnsureSuccess(rc);   // rc != 0 时抛 ChartSdkException

// 直接取描述文本
Console.WriteLine(NativeError.Describe((int)OgcErrorCode.OGC_ERROR_INVALID_PARAM));

OgcErrorCode（基础错误码实名枚举）

镜像 ogc_error_code_e（sdk_c_api.h 12 值：0 + -1..-11）。P/Invoke 层以 int 承载（ABI 等价），本枚举为 L2 类型化门面。

成员值含义
OGC_OK0成功。
OGC_ERROR_INVALID_PARAM-1非法参数。
OGC_ERROR_NULL_POINTER-2空指针。
OGC_ERROR_OUT_OF_MEMORY-3内存不足。
OGC_ERROR_NOT_FOUND-4未找到。
OGC_ERROR_OPERATION_FAILED-5操作失败。
OGC_ERROR_INVALID_STATE-6非法状态。
OGC_ERROR_IO_ERROR-7IO 错误。
OGC_ERROR_PARSE_ERROR-8解析错误。
OGC_ERROR_UNSUPPORTED-9不支持。
OGC_ERROR_INTERNAL-10内部错误。
OGC_ERROR_PERMISSION_DENIED-11权限拒绝。
