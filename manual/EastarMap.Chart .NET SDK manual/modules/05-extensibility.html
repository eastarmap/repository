⑤ 扩展点（命名空间 EastarMap.Chart.Extensibility）

本模块是 SDK 面向宿主应用的挂接点：日志接收（把 native 日志转发到宿主管线）与 JSON 序列化（编解码扩展）。默认均有开箱即用的实现。

与 native logger 对齐（sdk_c_api.h:128）：0=TRACE..5=FATAL。

Debug1

Warning3
Error4
Fatal5

ISdkLogSink / TraceLogSink（日志扩展点）

public interface ISdkLogSink { void Log(SdkLogLevel level, string message); }
L2 门面把 native 日志事件转发到宿主管线的扩展点。
public sealed class TraceLogSink : ISdkLogSink
System.Diagnostics.Trace 落点（默认接插件）。TraceLogSink.Instance 单例；输出格式 [ogc:{level}] {message}。

SdkLog（native 日志器控制）

把 native console/level 开关暴露给宿主。典型用途：基准与演示默认把 console 输出关到 ERROR，避免每帧 30+ 行 native 日志污染测量与录制。

public static bool ConsoleOutputEnabled { set; }
控制台输出开关（对应 ogc_logger_set_console_output）。logger 实例为空时确定性抛 ChartSdkException。
public static SdkLogLevel MinimumLevel { set; }
最低输出级别（对应 ogc_logger_set_level；数值与 native 0=TRACE..5=FATAL 一致）。

示例：关闭 native 控制台日志

using EastarMap.Chart.Extensibility;

// 关闭 native 控制台输出（避免日志污染）
SdkLog.ConsoleOutputEnabled = false;

// 只输出 ERROR 及以上级别
SdkLog.MinimumLevel = SdkLogLevel.Error;

// 自定义日志接收器
sealed class MySink : ISdkLogSink
{
    public void Log(SdkLogLevel level, string message)
        => File.AppendAllText("sdk.log", $"[{level}] {message}" + Environment.NewLine);
}
var sink = new MySink();  // 通过 DI/手动挂接到 L2 门面

ISdkJsonSerializer / StjJsonSerializer（JSON 序列化扩展点）

public interface ISdkJsonSerializer { string Serialize<T>(T value); T? Deserialize<T>(string json); }
attr_json / result 元数据的编解码契约。
public sealed class StjJsonSerializer : ISdkJsonSerializer
System.Text.Json 实现（默认接插件）。
public StjJsonSerializer(JsonSerializerOptions? options = null)
构造（默认 JsonSerializerDefaults.Web）。
public JsonSerializerOptions Options { get; }
实际使用的序列化选项。
public static StjJsonSerializer Instance { get; }
默认单例（JsonSerializerDefaults.Web）。

示例

using EastarMap.Chart.Extensibility;

var ser = new StjJsonSerializer();
var json = ser.Serialize(new { a = 1, b = "x" });
var obj  = ser.Deserialize<Dictionary<string, object>>(json);
典型用途 关闭 native 每帧日志以稳定性能测量、接入宿主的日志系统（NLog/Serilog）、自定义属性 JSON 编解码策略。
