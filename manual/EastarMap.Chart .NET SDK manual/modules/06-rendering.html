⑥ 渲染（命名空间 EastarMap.Chart.Rendering）

本模块是 SDK 的核心能力：图像设备（ImageDevice）与 Portrayal 渲染引擎（PortrayalEngine），用于把 S-57 图幅渲染为像素、载入要素。

类类别职责源文件
ImageDeviceIDisposable图像画布（创建/缩放/清屏/取像素/混合）Rendering\ImageDevice.cs
Rendering\PortrayalEngine.cs
PortrayalEngineIDisposable渲染引擎（ABI/创建+授权/图幅范围）
PortrayalEngineOptionsPOCO引擎接入选项（S52 根 + 后端 + 授权）
PortrayalRenderOptionsPOCO渲染选项（画幅/视口/等深线/显示类别…）
RenderOutputDTO渲染输出（像素 + 诊断/摘要）
PortrayalEngineRenderExtensionsstatic extRender / LoadFeatures 扩展方法
FeatureResultIDisposable要素查询结果（两段式枚举）

ImageDevice（图像设备门面）

封装 ogc_image_device_*。像素缓冲由 native 持有（get_pixels 返回内部指针 + size），复制后立即使用。IDisposable

public static ImageDevice Create(int width, int height)
创建图像设备（width/height 像素）。返回 NULL 抛 ChartSdkException。
public void Resize(int width, int height)
重设画幅（非 0 错误码抛异常）。
public void Clear()
清屏。
public int Width { get; }
画幅宽（像素）。
public int Height { get; }
画幅高（像素）。
public byte[] GetPixelsCopy()
native 内部像素快照（立即复制；BGRA8888 = width*height*4）。
public long NativePtr { get; }
设备句柄的 native 指针值（long long 直传）。
public void Blend(ImageDevice src)
把 src 混合到本设备（blend_pixels）。
public void SetDrawBackendConfig(string configPath)
设置绘制后端配置 JSON 路径。
public string GetBackendSummary()
后端摘要文本（const char* 静态存储）。

示例

using EastarMap.Chart.Rendering;

using var dev = ImageDevice.Create(512, 512);
dev.Clear();
var pixels = dev.GetPixelsCopy();          // 512*512*4 字节 BGRA
if (dev.Width != 512 || dev.Height != 512) throw new InvalidOperationException("尺寸异常");

using var overlay = ImageDevice.Create(512, 512);
dev.Blend(overlay);                           // 混合叠加层

PortrayalEngine（Portrayal 引擎门面）

ABI 探测 → engine_create（授权双路径）→ backend 配置 → 图幅 extent 探测。句柄生命周期由 SafeEngineHandle 托管。IDisposable

静态只读属性

public static uint AbiVersion { get; }
portrayal ABI 版本（引擎外静态探测；= OGC_PORTRAYAL_ABI_VERSION）。
public static ulong Capabilities { get; }
能力位图（OgcPortrayalCapability 位或集）。

静态方法

public static PortrayalEngine Create(PortrayalEngineOptions options)
创建引擎（engine_create；授权双路径经 security_config 传入）。options 为 null 抛 ArgumentNullException。

实例方法

public void SetBackendConfigPath(string path)
设置绘制后端配置路径（可运行期切换）。
public (double XMin, double YMin, double XMax, double YMax) GetChartExtent(string chartPath)
图幅地理范围探测（不渲染；CN422111.000 接入验证）。

PortrayalEngineOptions（引擎接入选项）

属性类型说明
S52RootPathstringS-52 资源根目录（含 portrayal.sdb；默认 = native 树 app_root）。
DrawBackendConfigPathstring?绘制后端配置 JSON（可空 = 引擎内建默认）。
LicenseFilePathstring?授权路径一：license 文件（如 config\license.lic）。
CredentialNamestring?授权路径二：凭据名（credential store 检索键；与 LicenseFilePath 二选一或同给）。
KeyVersionint?许可 key 版本（可选）。
DeployEnvironmentint部署环境实名（OgcPortrayalDeployEnvironment 数值）。

PortrayalRenderOptions（渲染选项）

最小必填 = 图幅路径 + 画幅尺寸；其余走引擎默认。

属性类型说明
Width / Heightint画幅尺寸（默认 256×256）。
Scaledouble视口比例（px/世界单位，即 px/度；<=0 = 整幅适配推导）。
CenterX / CenterYdouble视口中心（NaN = 取 extent 中心）。
PixelFormatint像素格式（1 = BGRA8888）。
ColorPaletteint色彩模式（0=DAY/1=DUSK/2=NIGHT）。
DisplayCategoryint显示类别（0=BASE/1=STANDARD/2=OTHER/3=ALL）。
SafetyContour / ShallowContour / DeepContourdouble安全/浅水/深水等深线（米；负值 = 引擎默认）。
DpiPolicy / CustomDpiint/doubleDPI 策略（0=PHYSICAL/1=FIXED_96/2=CUSTOM）及自定义 DPI。
SafetyDepthdouble安全水深（米；负值 = 不覆盖）。
EnableFourDepthShadesbool四级水深颜色（true=四级；映射 native TwoDepthShades 取反）。
ShowIsolatedDangersbool显示孤立危险物。
ShowSoundingbool显示水深注记。
ShowContourbool显示等深线。
ShowSafetyContourbool显示安全等深线。
StrictSafetyContourMatchbool安全等深线严格匹配（关闭容差）。

RenderOutput（渲染输出）

像素 + 诊断/摘要文本；result 句柄已释放后仍可读。

属性类型说明
Statusint渲染状态（0 = 成功）。
ErrorCodeint错误码。
Width / Height / Strideint画幅与行距。
PixelFormatint像素格式。
DisplayScaledouble显示比例。
Pixelsbyte[]BGRA8888 像素。
Diagnostic / BackendSummary / SecuritySummary / LicenseSummarystring诊断与各摘要文本。

PortrayalEngineRenderExtensions（渲染/载入扩展方法）

以扩展方法挂到 PortrayalEngine 上（engine.Render(...)）。

public static RenderOutput Render(this PortrayalEngine engine, string chartPath, PortrayalRenderOptions? options = null)
直渲图幅 → 像素 + 摘要。可见集由 ComputeViewportExtent 决定；Scale <= 0 默认整幅适配。
public static FeatureResult LoadFeatures(this PortrayalEngine engine, string chartPath)
载入图幅要素（load_features；filter 走引擎默认）。

示例：引擎创建 + 渲染 + 导出 PNG

using EastarMap.Chart.Rendering;
using EastarMap.Chart.Compatibility;

var root = EastarMapEnvironment.AppRoot;
using var engine = PortrayalEngine.Create(new PortrayalEngineOptions {
    S52RootPath = root,
    LicenseFilePath = Path.Combine(root, "config", "license.lic"),  // 授权双路径
});

var out = engine.Render(@"E:\CN422111.000", new PortrayalRenderOptions {
    Width = 1024, Height = 1024,
    ColorPalette = 0,        // DAY
    DisplayCategory = 1,     // STANDARD
    SafetyContour = 30,
});
if (out.Status != 0) Console.WriteLine("渲染失败：" + out.Diagnostic);
else
{
    // 像素 → Bitmap（WPF）
    var bmp = BitmapSource.Create(out.Width, out.Height, 96, 96,
        PixelFormats.Bgra32, null, out.Pixels, out.Stride);
    bmp.Freeze();
    // 或字节流落盘（见 15 端到端示例的 PngWriter）
}

// 图幅范围 + 要素枚举
var extent = engine.GetChartExtent(@"E:\CN422111.000");
using var feats = engine.LoadFeatures(@"E:\CN422111.000");
Console.WriteLine($"要素数 {feats.Count}；范围 lon[{extent.XMin},{extent.XMax}]");

FeatureResult（要素查询结果）

两段式要素枚举：count + 按索引取实名/显示名/属性 JSON。IDisposable

public int Count { get; }
要素数量。
public (long Rcid, int FeatureIndex) GetInfo(int index)
取要素元信息（rcid / feature_index）。
public string GetObjectClassName(int index)
对象类名（两段式 UTF-8）。
public string GetDisplayName(int index)
显示名（两段式 UTF-8）。
public string GetAttributeJson(int index)
属性 JSON（两段式 UTF-8）。

示例：枚举要素

using var feats = engine.LoadFeatures(chart);
for (int i = 0; i < feats.Count; i++)
{
    var (rcid, idx) = feats.GetInfo(i);
    Console.WriteLine($"#{i} rcid={rcid} class={feats.GetObjectClassName(i)} name={feats.GetDisplayName(i)}");
}
等深线一致性约束 native 契约 PortrayalRenderConfig::ValidateContours()：shallow ≤ safety ≤ deep，越界即 INVALID_PARAM。 门面只给 safety 时会把三元夹取为自洽值；如需同时设置多个等深线请遵守该序。

绘制族门面（B49–B51 批交付）

覆盖 ogc_draw_style_* / ogc_draw_device_* / ogc_draw_engine_* / ogc_image_*（Drawing/Imaging 命名空间）与 B50–B51 渲染支撑域（Rendering）。全部通过 10k 泄漏复验（ActiveCount 配对）。

类实况开发口径
DrawStyle（Drawing）create/destroy 真实；get_pen/brush/font 返回内部成员地址借出（生命周期随样式）；set_* 值拷贝装配装配后经成员视图读回一致；勿独立销毁借出句柄
DrawDevice（Drawing）真实设备工厂：1=RASTER/3=SVG/4=TILE/未知类型回退 Raster（据实）CreateRaster(w,h) 便捷入口；ImageBuffer 借出缓冲
DrawContext（Drawing）create 需非 NULL 设备；begin/end 配对；B8/T35 起 style 形参真实生效（draw_point/line/rect/fill_rect/text 经内核 SetStyle 状态消费；draw_geometry 带样式重载）；clip 按几何包络设裁剪矩形Clear(r,g,b,a) 后像素落设备缓冲；style 影响输出像素
DrawEngine（Drawing）B5/T21 起 create 真实——CApiDrawEngine + 离屏 RasterImageDevice(256×256)，句柄非 NULL；destroy NULL 安全真实引擎链走 PortrayalEngine；DrawEngine 亦可独立创建离屏引擎
SdkImage（Imaging）create 尺寸/通道/缓冲一致（get_data 可写、get_data_const 同缓冲别名）；save PNG 须 .png+4 通道；LoadFromFile 真实装载器（文件不存在/格式不支持才返 NULL → 门面抛）落盘走 SaveToFile；读回走 LoadFromFile
LabelEngine / LabelInfo（Rendering）B5/T22 起全真实：engine set_max_labels 往返一致（默认 100）、set_collision_detection 互逆语义、clear 清缓存；info 七项全真实（create 构造、get_text/get_x/get_y/set_text/set_position 生效）LabelEngine 与 LabelInfo 均可正常使用
HitTest（Rendering）B2/T09 起真实：create 返回堆上包装句柄（原悬垂指针已修）、destroy 配对、query_point/query_rect 接通真实 HitTester、free_features 真实释放数组创建/查询/释放全链可用；destroy 严格配对
RenderQueue / RenderTask（Rendering）B2/T01+T02 起真实：RenderTask::Create 委托 BasicRenderTask 真实产出；push/pop/FIFO 全链真实；pop 改 TryDequeue(0) 空队列立即返 null（死锁已修）；execute 返 1/0、is_complete/cancel 空包装防护（UB 已修）；pop 返回新堆包装（调用方 Dispose）队列/任务全链可用；pop 结果须 Dispose 配对
RenderOptimizer（Rendering）五项全真实：cache 开关往返一致 + clear 清计数可正常使用
RenderStats（Rendering）reset 真实清零 7 字段（结构往返）；累加侧无实名仅 reset 口径
RenderException（Rendering）create 真实（_strdup 拷贝 message/layer）；B3/T13 起 destroy 真实释放（free _strdup 串 + delete 堆块——原 no-op 泄漏已修）；error_code 恒 0字段经堆块直读；Create/Dispose 配对即可
OverlayComposite（Rendering）真实复合链（S-101 底层 → coverage 叠层）；NULL ds/coverage 或非正尺寸走 INVALID_PARAM 防护端到端真实出图随内核 FlatBuffers adapter 装配（已知限制 #10）；本批防护断言
PortrayalResultAdvanced（Rendering，内部）新式 6 实测：retain/release 配对、encode_image PNG 产物、write_image_stream 分块回调非空经 RenderHandle 内部路径使用
native 缺口收敛（据实，closeout §5.1 #18–#20） ① #5 HitTest 悬垂指针 —— 已随 B2/T09 修复（create 堆包装 + 查询真实）； ② #6 RenderTask::Create 恒空 + Pop 死锁 + UB —— 已随 B2/T01+T02 修复（任务工厂真实 + pop 非阻塞）； ③ #7 RenderException destroy no-op 泄漏 —— 已随 B3/T13 修复（真实释放）； ④ #4 ChartViewer.Render 设备 ABI 错配 —— 仍存（勿传非 NULL 设备，真实渲染链走本模块 PortrayalEngine.Render）。
