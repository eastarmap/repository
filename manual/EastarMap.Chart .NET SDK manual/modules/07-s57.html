⑦ S-57 解析（命名空间 EastarMap.Chart.S57）

本模块提供 S-57 海图文件的解析能力：一次性解析、增量分批解析（状态机），以及面向主机的进度驱动解析。S-57 样例图幅：E:\CN422111.000。

类类别职责源文件
S57ParserIDisposable一次性解析（open/parse/parse_file + 过滤）S57\S57Parser.cs
S57ParseConfigPOCO解析配置S57\S57Parser.cs
IncrementalParserIDisposable增量解析状态机S57\IncrementalParser.cs
IncrementalParserHostIDisposableiparser 主机 + 进度事件S57\IncrementalParserHost.cs
IncrementalParseResultDTO增量结果（has_changes/parse_time_ms）S57\IncrementalParserHost.cs
ParseProgressEventArgs事件参数进度事件（percent/phase）S57\IncrementalParserHost.cs

S57Parser（S-57 解析器门面）

create → open(CN422111.000) → parse/parse_file。解析结果指针由 parser 持有（无独立 destroy 导出，parser destroy 时一并释放）。IDisposable

静态方法

public static S57Parser Create()
创建解析器（入口先保证 native 库已按回退序加载）。返回 NULL 抛 ChartSdkException。

实例方法

public void Open(string path)
打开 S-57 数据文件（返 0 = 成功）。
public IntPtr Parse()
解析已打开的图幅；返回非 NULL 结果指针（parser 持有，勿手动释放）。
public IntPtr ParseFile(string path, S57ParseConfig? config = null)
打开并解析（一步）；config 为 null 时用默认配置。
public void SetFeatureFilter(IReadOnlyList<string> features)
设置要素类型过滤（char** 封装；native setter 契约为拷贝）。
public void SetSpatialFilter(double minX, double minY, double maxX, double maxY)
设置空间过滤（ogc_envelope_create_from_coords → 传入 → destroy 配对）。

示例：一次性解析

using EastarMap.Chart.S57;

using var parser = S57Parser.Create();
parser.Open(@"E:\CN422111.000");
var handle = parser.Parse();            // 结果句柄（parser 持有）

// 或一步打开+解析 + 配置 + 过滤
using var p2 = S57Parser.Create();
var cfg = new S57ParseConfig { IncludeMetadata = true, ValidateGeometry = true };
p2.SetFeatureFilter(new[] { "DEPARE" });          // 要素类型过滤
p2.SetSpatialFilter(121.0, 30.0, 123.0, 32.0);   // 空间范围过滤
var h2 = p2.ParseFile(@"E:\CN422111.000", cfg);

S57ParseConfig（解析配置）

镜像 ogc_parse_config_t。

属性类型说明
ValidateGeometrybool校验几何（默认 true）。
ValidateAttributesbool校验属性（默认 true）。
StrictModebool严格模式。
IncludeMetadatabool包含元数据（默认 true）。
MaxFeatureCountint最大要素数。

IncrementalParser（增量解析状态机）

create → start(path, batch) → parse_next/has_more 循环（pause/resume/cancel 可插）→ progress 探询；状态维护方法（has_file_changed/mark_processed/clear_state）。IDisposable

public static IncrementalParser Create()
创建增量解析器。
public void Start(string path, int batchSize)
启动增量解析（batch_size = 每批要素数）。
public void Pause()
暂停。
public void Resume()
恢复。
public void Cancel()
取消。
public IntPtr ParseNext()
解析下一批；批尽返回 IntPtr.Zero。
public bool HasMore()
是否还有未解析批次。
public double Progress()
进度（0.0–1.0）。
public bool HasFileChanged(string path)
文件是否变更。
public void MarkProcessed(string path)
登记已处理（状态推进）。
public void ClearState(string path)
清除路径状态。
public int ParseIncrementalBatch(string path, S57ParseConfig? config = null)
一次性增量批解析（带配置）；结果句柄用后释放。

示例：增量状态机循环

using EastarMap.Chart.S57;

using var ip = IncrementalParser.Create();
ip.Start(@"E:\CN422111.000", batchSize: 256);

while (ip.HasMore())
{
    var batch = ip.ParseNext();   // IntPtr.Zero = 批尽
    if (ip.Progress() > 0.5) ip.Pause();   // 可暂停
    // …处理 batch…
}

if (ip.HasFileChanged(@"E:\CN422111.000"))
    ip.MarkProcessed(@"E:\CN422111.000");

IncrementalParserHost（增量解析主机）

iparser 7 函数强类型 + ParseWithProgress 轮询驱动 0→100 进度事件。IDisposable

public static IncrementalParserHost Create(int format = 0)
按格式创建（S57 = 0）。
public int Open(string path)
打开海图文件（0 成功）。
public void Close()
关闭文件。
public int GetFormat()
格式枚举回读。
public IntPtr Parse()
全量解析（返回 ParseResult 不透明句柄；NULL = 失败）。
public IntPtr ParseIncremental(int batchSize)
增量批解析（batch_size 每批要素数；NULL = 无变更/批尽）。
public void ParseWithProgress(string path, EventHandler<ParseProgressEventArgs>? progress, int batchSize = 256)
轮询驱动解析：open → 全量 parse → 批循环（有界）→ 按序 raise 0→100 进度事件。

静态方法

public static IncrementalParseResult ParseIncrementalBatch(string path, S57ParseConfig? config = null)
单例增量批（带配置；不依赖 iparser 实例；解析器按调用即建即毁）。

示例：带进度的解析

using EastarMap.Chart.S57;

using var host = IncrementalParserHost.Create();
host.ParseWithProgress(@"E:\CN422111.000", (_, e) =>
    Console.WriteLine($"[{e.Phase}] {e.Percent}%"));   // 0→open→parse→batch→100 done

// 单例增量批
var res = IncrementalParserHost.ParseIncrementalBatch(@"E:\CN422111.000");
Console.WriteLine($"有变更 {res.HasChanges}，耗时 {res.ParseTimeMs} ms");

IncrementalParseResult（增量结果）

属性类型说明
HasChangesbool本次增量是否有变更。
ParseTimeMsdouble解析耗时（毫秒）。

ParseProgressEventArgs（进度事件参数）

属性类型说明
Percentint0–100。
Phasestring阶段名（open/parse/batch/done）。
典型流程 需要「一次性读全」用 S57Parser；需要「分块 + 可暂停/可恢复 + 进度」用 IncrementalParser； 需要「简单带进度」用 IncrementalParserHost.ParseWithProgress。解析结果通常接入 ② dump 模块入库。
