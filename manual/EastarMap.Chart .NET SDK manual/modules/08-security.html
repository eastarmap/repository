⑧ 安全（命名空间 EastarMap.Chart.Security）

本模块提供数据加密与安全库加载两类能力，用于保护敏感数据与校验被加载库的可信性。

类类别职责源文件
DataEncryptionIDisposable数据加解密Security\DataEncryption.cs
SecureLibraryLoaderIDisposable安全库加载 / 签名校验 / 信任库公钥读取Security\SecureLibraryLoader.cs

DataEncryption（数据加密门面）

封装 ogc_data_encryption_create/encrypt/decrypt/destroy 四函数。IDisposable

public static DataEncryption Create(string? key = null)
创建加密工具（key 当前由 native 忽略，保留契约位）。NULL 返回 → 确定性 ChartSdkException。
public byte[] Encrypt(byte[] plaintext)
加密（明文 → 密文；UTF-8 无关，字节级）。
public byte[] Decrypt(byte[] ciphertext)
解密（密文 → 明文）。

缓冲契约说明

output_size 为 in/out —— 入参缓冲容量，出参实际长度；容量不足直接返 -1 且不回填所需长度。 本门面按「自增缓冲重试」收敛（起始 = 明文长度 + 64，逐次翻倍，上限 64 MiB）。

native 限注（已归档） C API ogc_data_encryption_create 未调用 DataEncryption::Initialize，实现内 m_initialized==false → Encrypt/Decrypt 恒返回空向量。当前真机往返对空串成立；非空串往返待 native 补 Initialize。 见源码 DataEncryption.cs 类注释的解除建议。

示例

using EastarMap.Chart.Security;

using var enc = DataEncryption.Create("my-key");
var ct  = enc.Encrypt(Encoding.UTF8.GetBytes("敏感数据"));
var pt  = enc.Decrypt(ct);
Console.WriteLine(Encoding.UTF8.GetString(pt));   // 敏感数据

SecureLibraryLoader（安全库加载门面，可选件）

封装 ogc_secure_library_loader_create/load/verify_signature/destroy 四函数。IDisposable

public static SecureLibraryLoader Create(string allowedPaths)
创建安全加载器；allowedPaths 为允许路径白名单（分号分隔）。native 返回 NULL（stub）→ 抛 ChartSdkException（含 C 实名）。
public string AllowedPaths { get; }
允许路径白名单（分号分隔；native 当前忽略）。
public IntPtr Load(string libraryPath)
加载库（返回 native 库句柄；失败返回 IntPtr.Zero）。
public static bool VerifySignature(IntPtr libraryHandle, string publicKey, out int errorCode)
校验库签名（对照信任库公钥）。返回 false = 拒绝（errorCode 为 native 原始码）。
public static string? ReadTrustStorePublicKey(string trustStorePath)
读取信任库（trust_store.json）内首个 license-signing 公钥 PEM（含换行；缺失返 null）。
native 限注（已归档） C API 侧四函数当前均为 stub（sdk_c_api_plugin.cpp:400-417）： create 恒返 NULL、load 恒返 NULL、verify_signature 恒返 -1。 「篡改必拒」安全语义成立，但「正样本通过」待 native 实现。见源码 SecureLibraryLoader.cs 类注释。

示例：读取信任库公钥 + 签名校验

using EastarMap.Chart.Security;

var pem = SecureLibraryLoader.ReadTrustStorePublicKey(@"config\trust_store.json");
if (pem != null)
{
    var hLib = IntPtr.Zero;   // 由 Load 获得或外部句柄
    bool ok = SecureLibraryLoader.VerifySignature(hLib, pem, out int rc);
    Console.WriteLine($"签名校验：{(ok ? "通过" : "拒绝")}（rc={rc}）");
}

// create 目前为 stub → 会确定性抛 ChartSdkException
try { using var loader = SecureLibraryLoader.Create(@"C:\allowed"); }
catch (ChartSdkException ex) { Console.WriteLine(ex.Message); }
