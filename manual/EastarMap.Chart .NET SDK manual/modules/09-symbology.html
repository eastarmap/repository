⑨ 符号化（命名空间 EastarMap.Chart.Symbology）

本模块提供海图表达要素：颜色、画笔/画刷/字体、符号器与符号规则。

类 / 枚举类别职责源文件
SdkColorstatic颜色 5 函数（from_rgb/rgba/hex + to_hex/rgba）Symbology\Symbology.cs
Symbology\Symbolizer.cs
ColorValuestruct颜色值（r/g/b/a）
SdkPenIDisposable画笔（color/width/style）
SdkBrushIDisposable画刷（color/style）
SdkFontIDisposable字体（family/size/bold/italic）
Symbolizer / SymbolizerRuleIDisposable符号器 + 规则（比例尺区间判定/聚合）

公共枚举（PenStyle / BrushStyle / SymbolizerType）

三个公共枚举的值与 native ogc_pen_style_e / ogc_brush_style_e / ogc_symbolizer_type_e 对齐。

枚举成员值说明
PenStyleSolid0画笔实线样式。
BrushStyleSolid0画刷实填充样式。
SymbolizerTypeLine0线符号器类型。

用法示例：SdkPen.Create().SetStyle(PenStyle.Solid)、Symbolizer.Create(SymbolizerType.Line)。

SdkColor / ColorValue（颜色静态工厂与值类型）

ColorValue 是 ogc_color_t 的公共值类型镜像（r/g/b/a 字节）。SdkColor 封装 5 个往返函数。

ColorValue 属性

属性类型说明
R / G / B / Abyte红/绿/蓝/透明 0-255。

SdkColor 方法

public static ColorValue FromRgb(byte r, byte g, byte b)
RGB（alpha=255）。
public static ColorValue FromRgba(byte r, byte g, byte b, byte a)
RGBA。
public static ColorValue FromHex(uint hex)
0xRRGGBB 十六进制。
public static uint ToHex(ColorValue color)
转 0xRRGGBB。
public static (byte R, byte G, byte B, byte A) ToRgba(ColorValue color)
转 RGBA 分量。

示例

using EastarMap.Chart.Symbology;

var red    = SdkColor.FromRgb(255, 0, 0);
var orange = SdkColor.FromHex(0xFF8800);
var (r, g, b, a) = SdkColor.ToRgba(orange);
Console.WriteLine($"#{SdkColor.ToHex(orange):X6} = ({r},{g},{b},{a})");

SymbolizerRule（符号规则）

名称/比例尺区间 min/max + is_applicable 区间判定 + 符号器聚合。IDisposable

public static SymbolizerRule Create()
创建规则。
public string Name { get; set; }
规则名（往返 UTF-8）。
public double MinScale { get; set; }
比例尺下限。
public double MaxScale { get; set; }
比例尺上限。
public void SetScaleRange(double minScale, double maxScale)
一次设置区间。
public bool IsApplicable(void* feature, double scale)
区间判定（IsScaleInRange && Evaluate；无 filter 时恒真）。
public void AddSymbolizer(Symbolizer symbolizer)
附加符号器。
public void SetSymbolizer(Symbolizer symbolizer)
空规则时追加（与 AddSymbolizer 语义分立——不无界增长列表）。
public void SetFilter(Query.Filter filter)
设置要素过滤（影响 IsApplicable）。
public IntPtr GetFilter()
取过滤句柄（IntPtr.Zero = 无过滤）。
public IntPtr GetSymbolizer(int index)
按序取符号器（越界返 NULL）。

示例：规则 + 符号器聚合

using EastarMap.Chart.Symbology;

using var sym = Symbolizer.Create();
using var rule = SymbolizerRule.Create();
rule.Name = "航线显示";
rule.SetScaleRange(minScale: 1000, maxScale: 100000);
rule.AddSymbolizer(sym);                 // 聚合符号器

if (rule.IsApplicable(featurePtr, scale: 50000))
    sym.Symbolize(featurePtr, devicePtr);   // 命中区间 → 符号化
典型用途 自定义航线/航点表达样式（颜色/线宽/字体），或按比例尺区间切换不同符号。进阶场景常与 ⑥ 渲染模块联动。
