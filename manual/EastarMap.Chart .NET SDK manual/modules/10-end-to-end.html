⑮ 端到端完整示例

本页给出一个串联全部模块的可运行示例（脱胎于 samples\EastarMap.Chart.ConsoleSmoke\Program.cs）： 解析 → dump → 查询 → EDB → 渲染 → 导出 PNG。用于完整理解各模块的配合方式。

流程概览

步骤模块作用
0① 环境与版本版本握手（Version/BuildDate/VersionMatchesParts）+ native 根目录解析
1⑦ S-57 解析打开并解析样例图幅（parse / parse_file 双路径）
2② 数据dump 转 SQLite（带进度回调）+ 查询（cells/inspect/features）
3② 数据（EDB）用户航线库落库 + 中文属性归一
4⑥ 渲染引擎创建（授权双路径）+ 渲染图幅 → 像素
5⑥ 渲染像素导出 PNG（自包含 BGRA→PNG 编码）
6⑥ 渲染显示参数切换（DAY/BASE → NIGHT/ALL）复渲比对
7⑥ 渲染授权切换（license.lic vs 匿名引擎）对照授权摘要

完整代码

using System;
using System.IO;
using System.Linq;
using System.Text;
using EastarMap.Chart.Compatibility;
using EastarMap.Chart.Data;
using EastarMap.Chart.ErrorHandling;
using EastarMap.Chart.Rendering;
using EastarMap.Chart.S57;

const string Chart = @"E:\CN422111.000";

// ---- 0. 版本握手 + native 根（①）----
var version = SdkVersion.Version;
var root    = EastarMapEnvironment.AppRoot;            // native 树根
if (!SdkVersion.VersionMatchesParts)
    throw new InvalidOperationException("版本三元组握手失败：" + version);
Console.WriteLine($"版本 {version}（{SdkVersion.BuildDate}）");

// ---- 1. S-57 解析（⑦）----
long handle;
using (var parser = S57Parser.Create())
{
    parser.Open(Chart);
    handle = (long)parser.Parse();
}
using (var parser2 = S57Parser.Create())
{
    var h2 = (long)parser2.ParseFile(Chart, new S57ParseConfig { IncludeMetadata = true, ValidateGeometry = true });
    Console.WriteLine($"parse={handle} parse_file={h2}");
}

// ---- 2. dump → sqlite + 查询（②）----
var work   = Path.Combine(Path.GetTempPath(), "eastarmap-e2e");
Directory.CreateDirectory(work);
var sqlite = Path.Combine(work, "e2e.sqlite");
var dump   = ChartDump.Execute(
    new DumpOptions {
        Mode = "dump", SqlitePath = sqlite, Inputs = new[] { Chart },
        Overwrite = true, CreateSpatialIndex = true, BatchSize = 100,
    },
    (_, e) => { Console.WriteLine($"  dump {e.Current}/{e.Total} {e.FileName}"); return 1; });
if (!dump.Success) throw new InvalidOperationException("dump 失败：" + dump.Error);
Console.WriteLine($"入库要素 {dump.FeaturesInserted} 行");

var cells = FeatureQuery.ListCells(sqlite);
var cell  = cells.First();
var meta  = FeatureQuery.InspectCell(sqlite, cell);
var page  = FeatureQuery.QueryFeatures(sqlite, cell, new FeatureQueryFilter { Offset = 0, Limit = 5 });
Console.WriteLine($"数据集 {meta.CellId} 首页要素 {page.Count} / 总数 {FeatureQuery.CountFeatures(sqlite, cell)}");

// ---- 3. EDB 用户航线库 + 中文归一（②）----
var edb = Path.Combine(work, "e2e.edb");
using (var db = UserRouteDatabase.Open(edb))
{
    db.EnsureSchema();
    db.FeatureUpsert("user_waypoint", "wp-001", "POINT(122.51 31.22)",
        "{\"objectClass\":\"DEPARE\",\"名称\":\"航路点A\"}");
}
using (var db = UserRouteDatabase.Open(edb))
{
    var f = FeatureQuery.Normalize(db.FeatureGet("user_waypoint", "wp-001")!);
    Console.WriteLine($"EDB {f.ObjectClass} 名称={f.GetAttribute("名称")}");
}

// ---- 4. 渲染引擎（⑥）----
var licensePath = Path.Combine(root, "config", "license.lic");
using var engine = PortrayalEngine.Create(new PortrayalEngineOptions {
    S52RootPath = root,
    LicenseFilePath = File.Exists(licensePath) ? licensePath : null,
});
var output = engine.Render(Chart, new PortrayalRenderOptions {
    Width = 1024, Height = 1024,
    ColorPalette = 0, DisplayCategory = 1, SafetyContour = 30,
});
if (output.Pixels.Length == 0)
    throw new InvalidOperationException("渲染像素为空：" + output.Diagnostic);

// ---- 5. 导出 PNG（自包含 BGRA→PNG，参照 ConsoleSmoke\PngWriter.cs）----
var png = Path.Combine(work, "out.png");
PngWriter.WriteBgra32(png, output.Pixels, output.Width, output.Height);
Console.WriteLine($"已导出 {png}（{new FileInfo(png).Length} 字节）");

// ---- 6. 显示参数切换（DAY/BASE → NIGHT/ALL）----
var night = engine.Render(Chart, new PortrayalRenderOptions {
    Width = 1024, Height = 1024,
    ColorPalette = 2, DisplayCategory = 3, SafetyContour = 10,
});
Console.WriteLine($"切换后像素 {night.Pixels.Length} 字节（与原图 diff={DiffRatio(output.Pixels, night.Pixels):P2}）");

// ---- 7. 授权切换（有授权 vs 匿名）----
using var anonymous = PortrayalEngine.Create(new PortrayalEngineOptions { S52RootPath = root });
var anonOut = anonymous.Render(Chart, new PortrayalRenderOptions { Width = 512, Height = 512 });
Console.WriteLine($"有授权 license={output.LicenseSummary}；匿名 license={anonOut.LicenseSummary}");
代码说明 上例可直接运行（E:\CN422111.000 为样例图幅），其中两个工具辅助方法来自示例工程：
  • PngWriter.WriteBgra32(path, bgra, w, h) —— 自包含 BGRA8888→PNG 编码器，见 samples\EastarMap.Chart.ConsoleSmoke\PngWriter.cs；生产环境可用图像库替代。
  • DiffRatio(a, b) —— 两像素缓冲逐字节差异占比（samples\...\ConsoleSmoke\Program.cs 内置），用于显示参数切换前后的出图比对。
  • S-57 解析命名空间为 EastarMap.Chart.S57（S57Parser）。
  • 完整冒烟入口见 samples\EastarMap.Chart.ConsoleSmoke\Program.cs（L0/L1/integration 门禁段 + --nav 导航场景）。

生产级建议

  • 线程串行化：native 调用非线程安全时，用 SemaphoreSlim 串行化（见 samples\...\Demo.Wpf\Services\RenderService.cs 的 _gate）。
  • 句柄释放：所有 using 门面类，勿手动 free 由门面持有的 native 指针（如 S57Parser 的 parse 结果）。
  • 异步封装：长时间操作（dump/渲染）用 Task.Run + 进度回调/取消。
  • 授权切换：引擎可在创建时选 LicenseFilePath 或 CredentialName，支持运行时按授权等级渲染。
