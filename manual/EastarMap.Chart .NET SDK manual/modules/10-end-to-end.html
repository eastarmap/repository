⑩ 端到端完整示例

本页给出一个串联全部模块的可运行示例（脱胎于 samples\EastarMap.Chart.ConsoleSmoke\Program.cs）： 解析 → dump → 查询 → EDB → 渲染 → 导出 PNG。用于完整理解各模块的配合方式。

流程概览

步骤模块作用
0① 环境与版本版本握手 + native 根目录解析
1⑦ S-57 解析打开并解析样例图幅
2② 数据dump 转 SQLite + 查询
3② 数据（EDB）用户航线库落库 + 归一
4⑥ 渲染引擎创建 + 渲染图幅
5⑥ 渲染像素导出 PNG

完整代码

using System;
using System.IO;
using System.Linq;
using System.Text;
using EastarMap.Chart.Compatibility;
using EastarMap.Chart.Data;
using EastarMap.Chart.Rendering;
using EastarMap.Chart.S57;

const string Chart = @"E:\CN422111.000";

var root   = EastarMapEnvironment.AppRoot;        // ① native 根
var work   = Path.Combine(Path.GetTempPath(), "eastarmap-e2e");
Directory.CreateDirectory(work);
var sqlite = Path.Combine(work, "e2e.sqlite");
var edb    = Path.Combine(work, "e2e.edb");
var png    = Path.Combine(work, "out.png");

// ---- 0. 版本握手 ----
Console.WriteLine($"版本 {SdkVersion.Version}（{SdkVersion.BuildDate}），握 {SdkVersion.VersionMatchesParts}");

// ---- 1. S-57 解析（⑦）----
using (var parser = S57Parser.Create())
{
    parser.Open(Chart);
    var h = parser.Parse();
    Console.WriteLine($"解析句柄 {h}");
}

// ---- 2. dump → sqlite + 查询（②）----
var report = ChartDump.Execute(new DumpOptions {
    Mode = "dump", SqlitePath = sqlite, Inputs = new[] { Chart },
    Overwrite = true, CreateSpatialIndex = true, BatchSize = 100,
});
Console.WriteLine($"入库要素 {report.FeaturesInserted} 行");

var cells = FeatureQuery.ListCells(sqlite);
var cell  = cells.First();
var meta  = FeatureQuery.InspectCell(sqlite, cell);
Console.WriteLine($"数据集 {meta.CellId} 范围 lon[{meta.MinLon},{meta.MaxLon}] lat[{meta.MinLat},{meta.MaxLat}]");

var page = FeatureQuery.QueryFeatures(sqlite, cell, new FeatureQueryFilter { Limit = 5 });
Console.WriteLine($"首页要素 {page.Count}，总数 {FeatureQuery.CountFeatures(sqlite, cell)}");

// ---- 3. EDB 用户航线库（②）----
using (var db = UserRouteDatabase.Open(edb))
{
    db.EnsureSchema();
    db.FeatureUpsert("user_waypoint", "wp-001", "POINT(122.51 31.22)",
        "{\"objectClass\":\"DEPARE\",\"名称\":\"航路点A\"}");
}
using (var db = UserRouteDatabase.Open(edb))
{
    var f = FeatureQuery.Normalize(db.FeatureGet("user_waypoint", "wp-001")!);
    Console.WriteLine($"EDB {f.ObjectClass} 名称={f.GetAttribute("名称")}");
}

// ---- 4. 渲染引擎（⑥）----
using var engine = PortrayalEngine.Create(new PortrayalEngineOptions {
    S52RootPath = root,
    LicenseFilePath = File.Exists(Path.Combine(root, "config", "license.lic"))
        ? Path.Combine(root, "config", "license.lic") : null,
});
var output = engine.Render(Chart, new PortrayalRenderOptions {
    Width = 1024, Height = 1024, ColorPalette = 0, DisplayCategory = 1, SafetyContour = 30,
});
if (output.Status != 0) Console.WriteLine("渲染失败：" + output.Diagnostic);
else Console.WriteLine($"渲染 {output.Width}x{output.Height}，像素 {output.Pixels.Length} 字节");

// ---- 5. 导出 PNG（自包含 BGRA→PNG）----
WriteBgra32(png, output.Pixels, output.Width, output.Height);
Console.WriteLine($"已导出 {png}（{new FileInfo(png).Length} 字节）");

// ---- 简易 BGRA8888 → PNG 写盘（示例省略详细位图编码）----

代码说明 上例 WriteBgra32 为演示占位；真实代码中：
  • S-57 解析命名空间为 EastarMap.Chart.S57（S57Parser）。
  • PNG 编码请用图像库，或直接参照 samples\EastarMap.Chart.ConsoleSmoke\PngWriter.cs 的自包含编码器。

生产级建议

  • 线程串行化：native 调用非线程安全时，用 SemaphoreSlim 串行化（见 samples\...\Demo.Wpf\Services\RenderService.cs 的 _gate）。
  • 句柄释放：所有 using 门面类，勿手动 free 由门面持有的 native 指针（如 S57Parser 的 parse 结果）。
  • 异步封装：长时间操作（dump/渲染）用 Task.Run + 进度回调/取消。
  • 授权切换：引擎可在创建时选 LicenseFilePath 或 CredentialName，支持运行时按授权等级渲染。
