⑩ 导航（命名空间 EastarMap.Chart.Navigation）

阶段三（M4）新增模块：航线/航点/航迹/引擎/定位/偏航/碰撞/航行计算共 14 个门面类， 绑定 ogc_waypoint_* / ogc_route_* / ogc_track_* / ogc_route_manager_* / ogc_route_planner_* / ogc_navigation_engine_* / ogc_position_* / ogc_navcalc_* / ogc_collision_* / ogc_nmea_* / ogc_off_course_* 各域。所有权纪律：Route.AddWaypoint/InsertWaypoint 与 TrackRecorder 的 add 系吞引用转移所有权（容器析构统一释放），调用方对象随即失效； GetWaypoint/GetPoint/GetActiveRoute/GetCurrentTrack 均借出视图（不增引用，用完 Dispose 外壳即可）。

类职责源文件
Waypoint航点（16 函数：坐标/类型/半径/描述）Navigation\Waypoint.cs
Route航线（生命周期 12 + 计算/元数据 15 + 导入导出）Navigation\Route.cs
Track / TrackRecorder航迹与记录器（内核单例；stub 限注）Navigation\Track.cs、Navigation\TrackRecorder.cs
RouteManager / RoutePlanner航线表管理（9）/ 自动规划（3）Navigation\RouteManager.cs、Navigation\RoutePlanner.cs
RouteChecker航线校验（264 字节 C 布局手动解析）Navigation\RouteChecker.cs
NavigationEngine导航引擎（单例；状态机真实，四导航参数 B9/T38 起真实）Navigation\NavigationEngine.cs
PositionManager / PositionProvider定位事件化（样例）/ 数据源（模拟实现限注）Navigation\PositionManager.cs、Navigation\PositionProvider.cs
NavCalc / CollisionAssessorCPA/UKC 纯函数 / 碰撞评估（B9/T40 起真实）Navigation\NavCalc.cs、Navigation\CollisionAssessor.cs
NmeaParser / OffCourseDetectorNMEA 解析（B9/T41 起真实）/ 偏航检测（全真实）Navigation\NmeaParser.cs、Navigation\OffCourseDetector.cs

Waypoint（航点）

public static unsafe Waypoint Create(double latitude, double longitude)
创建航点（引用 1 归调用方；加入航线后所有权转移——原对象失效）。
public double Latitude/Longitude · public WaypointType Type · public double Radius/Speed
属性 getter（内核 ogc_waypoint_get_*）。注意：内核无 set_latitude/set_longitude 导出，坐标不可后改（创建时定死）。

Route（航线）

public static unsafe Route Create() · ImportFromFile(string path)（NativeError.EnsureSuccess）
空航线 / 从文件导入（RTZ）。
public unsafe void AddWaypoint(Waypoint waypoint) / InsertWaypoint(int index, Waypoint wp)
所有权转移：内核表存裸指针、容器析构统一释放；调用方航点对象立即失效（再访问抛 ObjectDisposedException）。
public unsafe Waypoint? GetWaypoint(int index)（借出视图）
按位取航点（不增引用）；用 using 释放外壳视图即可，不影响内核数据。
public int WaypointCount · CalcTotalDistanceM() · CalcRemainingDistanceM(lat, lon, currentIndex)
计数与距离计算（实例）。
public static double CalcLegBearingDeg(Waypoint from, Waypoint to) · CalcLegDistanceM(Waypoint from, Waypoint to) · CalcCrossTrackDistanceM(lat, lon, fromLat, fromLon, toLat, toLon) · CalcWaypointEtas(speedMps, startEpochSec, double[] outEtas)
计算族（静态，值参借用；ETA 写入 outEtas 数组）。
public unsafe void ExportToFile(string path) · GetTotalDistance() · SetId/SetName/SetStatus
导出 RTZ 与元数据读写。

示例：建航线 → 航段计算 → 导出

using EastarMap.Chart.Navigation;

using var route = Route.Create();
var wpA = Waypoint.Create(31.00, 120.00);   // 转移：调用方对象失效
var wpB = Waypoint.Create(31.10, 120.05);
route.AddWaypoint(wpA);
route.AddWaypoint(wpB);

Console.WriteLine($"航点数 {route.WaypointCount}，总距离 {route.CalcTotalDistanceM():F0} m");
var bearing = Route.CalcLegBearingDeg(wpA, wpB);      // 静态计算族
var legM    = Route.CalcLegDistanceM(wpA, wpB);
Console.WriteLine($"航段方位 {bearing:F1}°，距离 {legM:F0} m");

route.ExportToFile(@"D:\route.rtz");   // 注意：wpA/wpB 已转移，勿再单独 Dispose

RouteManager / RoutePlanner / RouteChecker

RouteManager：AddRoute(route)（裸存不增引用）· GetRoute(index)/GetRouteById(id) · GetActiveRoute()（借出）· SetActiveRoute(id) · RemoveRoute(id) · RouteCount
内核 RouteManagerContext 惰性单例；空 id 自动编 "route-N"。先 RemoveRoute 后才可 Dispose route。
RoutePlanner：PlanRoute(Waypoint start, Waypoint end, void[]? avoidAreas = null)
两点自动规划（avoid_areas 按 C 指针数组语义）；产出 Route 拥有（调用方负责 Dispose）。
RouteChecker：Check(route, minWaypointDistanceM=0, maxWaypointDistanceM=0, minTurnRadiusM=0) → RouteCheckResult[]
按 C 264 字节布局手动解析（severity/message/waypoint_index），结果数组经 ogc_route_check_result_array_destroy 释放。

NavigationEngine / PositionManager / PositionProvider

NavigationEngine：Create()（内核单例）· Initialize()=1/0 · SetRoute(route)（裸持）· Start/Stop/Pause/Resume/Shutdown
四导航参数 GetCrossTrackError/GetDistanceToWaypoint/GetBearingToWaypoint/GetCurrentWaypoint B9/T38 起真实：状态机真实（start→Active/pause→Paused/stop→Inactive，get_status 映射四态）； 三量经内核导航计算器按注入位置产出（未注入位置为初始 0 值，据实返回）；get_current_waypoint 借出活动航线当前索引航点。
PositionManager：Create() · SetCallback(Action?)（事件化）· GetPosition(out lat, out lon) · Initialize/SetPosition
事件化样例（WP0.4）：回调经 GCHandle thunk 转发（Interop 层 CallbackGuard/NativeCallback）， 注册/覆写/注销自动配对。内核无回调注销 API → 注销用 no-op thunk 占位。内核单例；Initialize/SetPosition 为 stub 恒返 0（无注入触发源——触发链验证见 ⑪ 模块联动）。
PositionProvider：CreateSerial(port, baud) / CreateNetwork(host, port)（构造即 Initialize，失败返 null）· Connect · Dispose（真实 Shutdown+delete）
内核为模拟实现：不校验设备存在（任意串口名 IsConnected=true）、Connect 恒 0——限注。

NavCalc（纯函数）/ CollisionAssessor / NmeaParser / OffCourseDetector

NavCalc.CpaCalculate(own×4, target×4) → CpaResult(Cpa, Tcpa, Bearing, DangerLevel)
最近会遇点/时间（两船运动学外推；纯函数无状态）。
NavCalc.UkcCalculate(chartedDepth, tideHeight, draft, speed, squatCoeff) → UkcResult(…, Safe)
富余水深：海图深/潮高直通、Safe ⟺ Ukc ≥ 0（内核公式黑盒——精确式见索引 T3.6.3 待查清单）。
CollisionAssessor.Create()（内核单例）· Assess(…, void* target) → 结果或 null（B9/T40 起真实）
内核 AssessTarget 真实：GeoPoint 距离/方位 + CPA/TCPA 阈值（2.0nm/30min）风险判定；target 为 NULL 时返 null；结果经 FreeRisk 释放。
NmeaParser.Create()（内核单例）· Parse(sentence) → bool（真实）· SentenceType（B9/T41 起真实）
解析结果读取口 B9/T41 起真实：GetLatitude/GetLongitude/GetSpeed/GetCourse + get_sentence_type （最近成功句型如 "GPRMC"，未解析时空串）。C API 层缓存最近一次成功解析的 PositionData（进程级，多句柄共享）。
OffCourseDetector.Create()（内核单例）· SetThreshold(detector, meters) · Check(detector, lat, lon, from, to) → DeviationResult
全真实：航段中点 XTE≈0、偏航点距离显著非零；Side 恒 0（内核未填方向——限注）。

示例：偏航检测 + CPA

using EastarMap.Chart.Navigation;

unsafe
{
    var detector = OffCourseDetector.Create();
    OffCourseDetector.SetThreshold(detector, 463.0);        // 0.25 海里
    using var from = Waypoint.Create(31.00, 120.00);
    using var to   = Waypoint.Create(31.10, 120.00);       // 正北航段

    var onRoute  = OffCourseDetector.Check(detector, 31.05, 120.00, from, to);
    var offRoute = OffCourseDetector.Check(detector, 31.05, 120.10, from, to);
    Console.WriteLine($"航线内 XTE={onRoute.CrossTrackError:F1}m / 偏航距离={offRoute.DistanceToRoute:F0}m");

    var cpa = NavCalc.CpaCalculate(31.0, 120.0, 5.0, 0.0,  30.9, 120.0, 5.0, 180.0);
    Console.WriteLine($"CPA={cpa.Cpa:F0}m TCPA={cpa.Tcpa:F0}s 危险级={cpa.DangerLevel}");
}
