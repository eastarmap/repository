⑪ 预警（命名空间 EastarMap.Chart.Alerts）

阶段三（M4）新增模块：告警快照 / 告警引擎 / 告警区带三件——绑定 ogc_alert_*（16+array_destroy）/ ogc_alert_engine_*（13）/ ogc_alert_zone_*（4）。区带判定与告警属性快照为内核全真实； 引擎的登记/确认/移除真实，事件触发链 B9/T42 起收口（get_alert/alert_count/set_callback/clear_alerts 全真实——见下表）。

类职责源文件
Alert告警快照（16 函数 + array_destroy）Alerts\Alert.cs
AlertEngine告警引擎（13 函数；登记/确认/移除真实链）Alerts\AlertEngine.cs
AlertZoneGeoJSON 区带（圆形/多边形；全真实）Alerts\AlertZone.cs

Alert（告警快照）

public static unsafe Alert Create(int type, int level, string message)
创建告警（引用 1 归调用方）。内核实况：create 丢弃 type 实参（event_type 硬编码 "alert"）→ Type getter 恒 0（PS-9 限注）；level/message 正常。
public long Id · string Message · int Level/Type · bool IsAcknowledged · Timestamp
八属性往返（message/level/acknowledged 等）。Timestamp 内核写 long 读 double（跨型）——断言 > 0 即可。
public void SetPosition(Geometry.Coordinate c) · GetPosition()（X=经度 Y=纬度）
位置语义：内核 ogc_coordinate_t 直通——X 为经度、Y 为纬度（与常见 Lat/Lon 顺序相反，注意）。
public static unsafe void DestroyArray(void** array, int count)
批量销毁（内核批读配套）。

AlertEngine（告警引擎）

public static unsafe AlertEngine Create()（内核 ctx 惰性单例）· Initialize()（真实 0/-1）· Shutdown()
EngineConfig 缺省（1s 检查间隔 + 去重 60s）。
public unsafe int AddAlert(Alert alert)（所有权转移）
表存 wrapper 裸指针且 ctx 析构统一 delete → 调用方 Alert 对象立即失效；引擎 Dispose 即统一释放。 门面已强制先 Initialize（内核缺陷：未初始化引擎直接 add 会致析构崩溃，PS-9 归档）。
public unsafe void AcknowledgeAlert(Alert alert)（add 前调用）· RemoveAlert(id)（B3/T16 起真实表删即释放）
确认走 acknowledge service（wrapper 置位）+ 登记。RemoveAlert B3/T16 起真实（delete wrapper 后 erase，原表删不 delete 泄漏已关闭）。
public Alert? GetAlert(id)（B9/T42 起真实）· AlertCount（B9/T42 起真实）· SetCallback（B9/T42 起真消费）· ClearAlerts（B3/T16 起真实）· CheckAll
事件触发链 B9/T42 起收口：get_alert 按 id 查表借出、get_alert_count 读 activeAlerts.size()（原 ctx 指针混用 AV 已修）、 set_callback 真消费（check_all 注入链 AIS→碰撞→告警触发宿主回调）、clear_alerts 真实清表释放。

示例：告警创建 → 确认 → 入引擎 → 统一释放

using EastarMap.Chart.Alerts;

using var engine = AlertEngine.Create();
engine.Initialize();

var alert = Alert.Create(1, 2, "区带入侵告警");
alert.SetPosition(new EastarMap.Chart.Geometry.Coordinate(120.05, 31.05, 0, double.NaN));
engine.AcknowledgeAlert(alert);              // add 前确认（转移后外壳失效）
Console.WriteLine($"已确认: {alert.IsAcknowledged}");
engine.AddAlert(alert);                      // 所有权转移：alert 对象至此失效
// 引擎 Dispose 时内核统一释放——无需（也不可）再 Dispose alert

AlertZone（GeoJSON 区带）

public static unsafe AlertZone CreateFromGeoJson(string geoJson)（内核全真实）
两种契约（alert_zone.cpp:94 实证）："Point" + "coordinates":[lon,lat] + "radiusM":>0 → 圆形区带；"Polygon" coordinates → 单环多边形（≥3 顶点）。 解析失败抛 ChartSdkException 并附 ogc_alert_zone_get_last_error 文本。
public AlertZoneCheckResult CheckPoint(double latitude, double longitude)
区内 Inside=true 且 DistanceM=进入深度（到最近边界）；区外 DistanceM=到最近边界距离。

示例：圆形区带入侵判定

using EastarMap.Chart.Alerts;

using var zone = AlertZone.CreateFromGeoJson(
    "{\"type\":\"Point\",\"coordinates\":[120.05,31.05],\"radiusM\":2000}");

var hit = zone.CheckPoint(31.05, 120.05);      // 圆心 → 必入区
var far = zone.CheckPoint(31.50, 120.05);      // 0.45° 纬度 ≈ 50km → 区外
Console.WriteLine($"入区={hit.Inside} 进入深度={hit.DistanceM:F0}m；区外距离={far.DistanceM:F0}m");
