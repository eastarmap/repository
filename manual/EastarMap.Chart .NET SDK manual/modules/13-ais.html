⑫ AIS 目标（命名空间 EastarMap.Chart.Ais）

阶段三（M4）新增模块：AisTarget 全真实（目标对象引用计数生命周期 + 运动学字段直写直读）、 AisManager 内核单例（initialize/shutdown/get 真实；注入与事件链 B9/T42 起真实）。绑定 ogc_ais_target_*（12）/ ogc_ais_manager_*（10）。

类职责源文件
AisTargetAIS 目标（12 函数，内核全真实）Ais\AisTarget.cs
AisManager目标管理器（内核单例；注入与事件链 B9/T42 起真实）Ais\AisManager.cs

AisTarget（AIS 目标）

public static unsafe AisTarget Create(uint mmsi)（引用 1 归调用方）
创建目标；destroy = 内核 ReleaseReference（引用计数，非直接 delete）——Dispose 幂等配对。
public uint Mmsi · string Name（缓冲拷贝读）· int NavStatus · double Heading
标识与状态族（内核真实）。NavStatus 为 AIS 航行状态枚举值（0–15）。
public double Latitude/Longitude/Speed/Course · public void UpdatePosition(lat, lon, speed, course)
运动学四字段直写直读（内核 Set*/Get* 真实）。单位：度 / 节（内核字段语义，§15.9 单位注）。

示例：目标创建 → 更新 → 读回 → 释放

using EastarMap.Chart.Ais;

var target = AisTarget.Create(412345678u);
try
{
    target.UpdatePosition(31.02, 120.02, speed: 12.5, course: 95.0);
    Console.WriteLine($"MMSI {target.Mmsi} @ ({target.Latitude:F4}, {target.Longitude:F4}) " +
                      $"{target.Speed:F1}kn / {target.Course:F0}°");
}
finally { target.Dispose(); }   // ReleaseReference 配对（幂等）

AisManager（目标管理器）

public static unsafe AisManager Create()（内核单例——多门面对象共享同一表）
create = AisManager::Instance()、destroy 空操作——外壳 Dispose 幂等，不触内核。
public int Initialize()（真实 1/0）· Shutdown()（真实）· int TargetCount（真实）· GetTarget(mmsi)（借出）
查询族真实；count/get_target 随 B9/T42 注入入口真实化（注入后 count 递增、get 可取回）。
public unsafe int AddTarget(void* target) / int RemoveTarget(mmsi)（B9/T42 起真实）· SetCallback（B9/T42 起真消费）· FreeTargets（真实）
B9/T42 注入链收口：add_target = 内核 AddTarget（所有权转移，注入成功（返 0）后调用方不得再 destroy；同 MMSI 替换）、 remove_target = ReleaseReference + 摘表、set_callback 真消费（event_type 0=目标更新）、free_targets 真实 free 数组（目标对象归管理器）。

所有权纪律速查（据实归档）

接口实况处置
AisManager.AddTargetB9/T42 起真实：所有权转移（返 0 后调用方不得再 destroy；同 MMSI 替换）注入后交由管理器统一释放
