⑬ 图层 / 视图 / 变换（命名空间 EastarMap.Chart.Layers / Viewer / Transform）

本模块覆盖 B44–B48 批交付的图表组织与显示链门面：图层装载与排序（Layers）、图表查看与命中（Viewer）、坐标变换（Transform）。所有门面已通过 450+ 单测门禁（ActiveCount 配对 + 行为据实断言）。

LayerManager 图层登记与排序示例

using EastarMap.Chart.Layers;

using var mgr = LayerManager.Create();

// 以 Layer 门面登记进管理器（AddLayer 不夺所有权——层仍归调用方，
// 仅 LayerGroup.AddLayer 才转移所有权，勿混同）
using var layer = LoadSomeLayer();   // 由 VectorLayer/MemoryLayer 等产出（Owned）
mgr.AddLayer(layer);

int count = mgr.LayerCount;
mgr.SetLayerVisible(0, true);
mgr.SetLayerOpacity(0, 0.8);
// MoveLayer 语义：内核 erase + 补偿插入——
// move(0, 2) 在 [A,B,C] 上得 [B,A,C]（toIndex>from 时 insertIndex--）
mgr.MoveLayer(0, 2);
var layer0 = mgr.GetLayer(0);        // 借出视图；用完 Dispose 外壳即可（不影响内核层）

mgr.RemoveLayer(0);                    // 仅摘除登记，不销毁层
using var owned = LoadSomeLayer();  // Owned 层仍须由调用方显式释放
mgr.AddLayer(owned);
owned.Dispose();                       // 层生命周期归调用方（管理器不接管）

ChartViewer 查看与命中示例

using EastarMap.Chart.Viewer;

using var viewer = ChartViewer.Create();
viewer.LoadChart(@"E:\CN422111.000");
viewer.SetViewport(121.0, 31.0, 1000.0);     // 中心 + 比例
if (viewer.HasFeatureAt(121.0, 31.0))      // 命中判定（真实方法名）
{
    var (wx, wy) = viewer.ScreenToWorld(48, 48);   // 屏幕坐标 → 世界坐标
}
// 限注（native 缺口 #4）：Render(device, w, h) 在传非 NULL 设备时为
// 内核 ABI 错配（未定义行为，实测进程崩溃）——真实渲染链走 ⑥
// PortrayalEngine.Render，本门面仅保持 NULL/非法尺寸 -1 防护。

CoordTransformer CRS 变换示例

using EastarMap.Chart.Transform;

using var t = CoordTransformer.Create("EPSG:4326", "EPSG:3857");
var (x, y) = t.Transform(121.0, 31.0);    // 经纬度 → Web 墨卡托（米）
var (lo, la) = t.TransformInverse(x, y);    // 往返互逆（往返零误差口径 <1e-6）
// 已知点互验：121°E → 13469385.31m、31°N → 3627892.19m（<1e-6）
// B8/T37 起：未知 CRS 对 IsValid=false，Transform/TransformInverse 显式抛 ChartSdkException（不再静默透传）
