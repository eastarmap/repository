⑭ 手册覆盖范围：已封装接口 vs 未封装接口

本页界定本手册的覆盖边界，帮助二次开发快速判断某个能力是否可直接调用， 以及当能力「未封装」时应如何处理。是使用本手册各模块前的总纲。

SDK 分层溯源链 ogc_chart_c_api（C ABI，ogc_* 导出，931 个） → L1 EastarMap.Chart.Interop（P/Invoke 绑定，929 个，域 108——仅 JNI 2 项不属 .NET 范围未绑定） → L2 EastarMap.Chart（本手册对象，托管门面，929 个引用——v1.4 索引口径，2026-11-13 M6） → 测试/示例（测试覆盖 73 项）。二次开发只应使用 L2 门面，禁止直接 P/Invoke（架构守卫强制）。

已封装（本手册覆盖，二次开发可用）

可用范围 仅 EastarMap.Chart（L2 门面层，929 个 native 引用）对应的托管类/方法， 按 Compatibility / Data / Display / ErrorHandling / Extensibility / Geo / Geometry / Layers / Query / Rendering / S57 / S101 / Security / Symbology / Transform / Viewer / Drawing / Imaging / Coverage / Navigation / Alerts / Ais 等命名空间划分，即本手册各模块所记录的全部内容。 这些门面类均实现 IDisposable（句柄安全释放），并统一以 ChartSdkException 暴露 native 错误。

未封装（本手册不覆盖，二次开发不可直接调用）

禁止直接 P/Invoke native ogc_chart_c_api 共 931 个 ogc_* 导出，当前 未封装 2 项（仅 JNI，B58 全量对账收口）：
  • L1 未绑定 2 项：ogc_jni_exception_create / ogc_jni_exception_destroy（JNI 专用，不属 .NET 范围，永久排除）。
  • 阶段五（B53–B59）已将离线 / 瓦片 / 缓存 / 熔断 / 错误恢复 / 优雅降级 / 性能 / 插件驱动 / 库加载 / LOD / 插件管理 / 健康检查 等 118 项补全为 L2 门面，未封装已收口至仅 JNI 2 项。
  • 未封装项在 L2 无门面类，二次开发不得绕过封装直接 P/Invoke（架构守卫强制，且可能缺安全释放）。最终收口判据（B58）：未封装 = 2（仅 JNI）。

边界判定方法

判断某个能力是否已封装：在 src\EastarMap.Chart\** 中是否存在对应 public 门面类/方法。

判定含义处置
存在 public 门面类/方法已封装见本手册对应模块直接使用；句柄用 using 释放。
不存在对应 public 门面未封装勿直接使用（勿绕过封装 P/Invoke）；仅在确实需要时向 SDK 提供方登记需求。
「仅部分封装」的域门面存在但内核某子接口为 stub/限注各模块内已按实况标注（如内核 stub 组、native 缺口、据实限注）。

常见「仅部分封装」的域已在对应模块内标注：如 ⑥ 渲染的 native 缺口 #4（ChartViewer.Render 设备 ABI 错配）、⑩ 导航的 Track stub 组与 PositionManager/PositionProvider 模拟限注、⑪ 预警的 Alert.Type 跨型、⑫ AIS 的 AddTarget 所有权纪律等，均按内核实况限注据实标明。

分层关系与所有权纪律

  • L1（Interop）为 P/Invoke 原始绑定，仅供 L2 门面内部使用；二次开发不得直接触碰。
  • L2（门面）是本手册对象：统一做 UTF-8 编解码、错误码→ChartSdkException 映射、句柄安全释放、双 TFM（net8.0 / net472）同构。
  • 所有权纪律：add 系（如 Route.AddWaypoint、LayerManager.AddLayer）吞引用转移所有权，调用方对象随即失效；get 系（如 GetWaypoint、GetLayer）借出视图，用完 Dispose 外壳即可。
